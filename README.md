# 삼국지 200대 핵심 지명 대지도 · 三國志 歷史地理 大圖鑑

> 정사 『삼국지』와 『삼국지연의』에 나오는 핵심 지명 200곳을 한 장의 인터랙티브 지도에 담은 웹 도감입니다.
> 설치 없이 브라우저에서 바로 열립니다.

**🔗 바로 보기:** https://koala-penguin.github.io/three-kingdom-map/

---

## 소개

낙양, 허창, 적벽, 성도, 오장원처럼 삼국지를 읽다 보면 계속 나오는 지명들이 있습니다. 이 지도는 그런 지명들이 실제로 어디에 있었는지, 무슨 일이 있었는지, 지금은 어느 도시인지를 한눈에 볼 수 있게 정리했습니다.

- 지명 **200곳**을 중요도·유명도 순서(1위~200위)로 정리했습니다.
- 지명마다 **5장짜리 상세 카드**가 있습니다.
  1. 개관/지략
  2. 정사 기록
  3. 연의 서사
  4. 현대 위치
  5. 문헌 출처
- 모든 지명에 **현대 행정구역 위치**를 적었습니다. 예: 낙양 → 중국 허난성 뤄양시.

## 주요 기능

### 🗺️ 인터랙티브 지도
- 드래그나 터치로 지도를 이동하고, 마우스 휠이나 핀치로 확대·축소합니다.
- 확대할수록 더 많은 지명 카드가 펼쳐집니다.
- **권역 이동**으로 원하는 권역에 바로 갈 수 있습니다.
  - 중원(사례·예주·연주)
  - 하북·요동
  - 관중·서량
  - 강동·회남
  - 중국 전도
- **주요 지형:** 황하, 장강, 한수, 위수, 회수, 장강 삼협
- **후한 13주 표시:** 사례, 예주, 연주, 기주, 병주, 유주, 청주, 서주, 양주(揚), 형주, 익주, 양주(凉), 교주, 남중
- **진영별 색 구분:** 조위, 촉한, 손오 거점이 서로 다른 색으로 표시됩니다.
- **화면 모드:** 🌙 다크 모드와 📜 고지도 양피지 모드
- **보기 방식:** 지도+카드 분할 보기, 그리고 🗂️ 200선 도감 그리드 보기

### 🚩 역사 대장정 투어
주요 사건의 동선을 순서대로 따라가는 가이드 투어입니다.
1. 🔥 반동탁 연합·관도대전 (10곳)
2. 🌊 적벽대전·삼국정립 가도 (9곳)
3. ⛰️ 유비 입촉·한중 공방전 (9곳)
4. ⚔️ 관우 번성 북벌·이릉대전 (8곳)
5. 🌟 제갈량 남정·5차 북벌 가도 (9곳)
6. 🛡️ 합비·유수구·회남 전선 (6곳)
7. 🐎 음평 기습·삼국 통일 가도 (8곳)

### 🔍 검색 · 필터 · 정렬
- **유형별 필터:**
  - 🏯 수도·거점
  - ⚔️ 전장·요충
  - 🛡️ 관문·요새
  - 👑 군웅 할거지
  - 📜 고향·사적
- **순위 구간:**
  - 최상위 1~30위
  - 상위 50선
  - 51~100위
  - 101~150위
  - 151~200위
- **정렬:** 중요도 순, 중요도 역순, 가나다 순, 해설 분량 순
- **관련 인물 링크:** 인물을 클릭하면 그 인물과 관련된 지명이 모두 검색됩니다.
- **즐겨찾기 ★**와 **명소 랜덤 탐방** 기능
- **인접 거점 정보:** 가까운 거점까지의 직선거리(km)를 보여 주고, 클릭하면 바로 이동합니다.

### 🔗 출처
- 지명 고증은 담기양(譚其驤) 『중국역사지도집(中國歷史地圖集)』 제3권을 기준으로 했습니다.
- 거리는 Google Maps 좌표로 실측했습니다.
- 지명마다 위키백과(한·중), 나무위키, Wikimedia Commons 원문 링크가 붙어 있습니다.

## 사용법

- **온라인:** 위 링크로 접속하면 됩니다.
- **오프라인:** `index.html`을 내려받아 브라우저로 열면 됩니다. 이미지가 모두 파일 안에 들어 있습니다.
  다만 레이아웃(Tailwind CDN)과 폰트(Google Fonts)를 불러오려면 인터넷 연결이 필요합니다.
- **지원 기기:** PC와 모바일 모두 지원하며, 터치와 핀치 줌을 쓸 수 있습니다.

## 기술

- 파일 하나(`index.html`, 약 5MB)로 된 정적 웹앱입니다. 서버나 빌드 과정이 필요 없습니다.
- 사용 기술: HTML, Tailwind CSS, Vanilla JavaScript
- 이미지는 Base64로 파일 안에 넣었습니다.
- GitHub Pages로 호스팅합니다.
